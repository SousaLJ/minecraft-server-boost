## English

Public documentation, support, and issue-tracking repository for **Minecraft Server Boost**.

The current **1.0.0-beta.1** line targets Minecraft 1.21.1 / Java 21 on Forge and NeoForge.

### Features

- regular kits and Choice Kits;
- server-only vanilla GUI for selection and `/kit info`;
- built-in permissions and optional FTB Ranks integration;
- MineSkin integration with a protected, rate-limited `/setskin`;
- first-login, returning-player, and logout messages;
- periodic announcements using `SEQUENTIAL`, `RANDOM`, and `SHUFFLE`;
- pt-BR, en-US, fr-FR, and es-ES mod messages.

> Source code is maintained separately in the private
> `SousaLJ/minecraft-server-boost-sources` repository.
