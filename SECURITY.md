# Security policy / Política de segurança

## English

Do not open a public Issue for vulnerabilities, permission bypasses, exposed
tokens, or failures that could compromise servers. Use GitHub private
vulnerability reporting:

`https://github.com/SousaLJ/minecraft-server-boost/security/advisories/new`

Include the mod, modloader, and Minecraft versions, impact, minimal reproduction
steps, and a safe way to verify the fix.

Never submit MineSkin tokens, passwords, private addresses, full world files,
player personal data, or unsanitized logs.

## Português

Não abra uma Issue pública para vulnerabilidades, bypasses de permissão,
exposição de tokens ou falhas que possam comprometer servidores. Use o relato
privado de vulnerabilidades do GitHub:

`https://github.com/SousaLJ/minecraft-server-boost/security/advisories/new`

Inclua as versões do mod, modloader e Minecraft, impacto, passos mínimos de
reprodução e uma forma segura de confirmar a correção.

Nunca envie token MineSkin, senhas, endereços privados, mundos completos, dados
pessoais de jogadores ou logs sem sanitização.
