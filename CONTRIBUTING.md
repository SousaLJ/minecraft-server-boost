# Contributing / Como contribuir

## English

This repository accepts improvements to documentation, documentation
translations, support forms, and configuration examples without sensitive data.

Before opening a pull request:

1. create or reference an Issue for non-trivial changes;
2. keep documentation tied to the stated mod version;
3. do not submit mod source code, JARs, libraries, or extracted files;
4. do not include tokens, private IPs, or player data;
5. run `mkdocs build --strict`;
6. update both languages or clearly identify the translation still required.

## Português

Este repositório aceita melhorias na documentação, traduções, formulários de
suporte e exemplos de configuração sem dados sensíveis.

Antes de abrir um pull request:

1. crie ou relacione uma Issue para mudanças não triviais;
2. mantenha a documentação vinculada à versão informada;
3. não envie código-fonte, JARs, bibliotecas ou arquivos extraídos do mod;
4. não inclua tokens, IPs privados ou dados de jogadores;
5. execute `mkdocs build --strict`;
6. atualize os dois idiomas ou identifique claramente a tradução pendente.
