# Privacidade

O repositório público não precisa receber dados de mundo ou credenciais para
diagnosticar a maioria dos erros.

## Dados locais do mod

- `player_data.json` pode conter UUIDs e nomes;
- `permissions.json` contém UUIDs, nomes e decisões administrativas;
- `skin_cache.json` contém nomes, UUIDs e propriedades assinadas de textura;
- `config.toml` pode conter o token MineSkin;
- logs podem conter IPs, nomes, caminhos locais e mensagens.

Faça uma cópia, remova ou substitua esses valores e só então anexe o arquivo.
Nunca edite o arquivo original do servidor para “sanitizá-lo”.

## Retenção pública

Conteúdo enviado a Issues e Discussions pode permanecer no histórico mesmo
após edição. Caso publique uma credencial, revogue-a imediatamente e avise o
mantenedor; não dependa apenas da exclusão do comentário.
