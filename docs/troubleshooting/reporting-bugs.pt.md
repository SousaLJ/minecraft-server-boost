# Como relatar um bug

Um bom relato permite reproduzir o problema sem acesso ao seu servidor.

Inclua:

- versão exata do Minecraft Server Boost;
- Minecraft, modloader e Java;
- servidor dedicado ou integrado;
- backend de permissão e versão do FTB Ranks, quando aplicável;
- sequência mínima de comandos ou ações;
- resultado esperado e obtido;
- `latest.log` e crash report completos, sanitizados;
- teste de isolamento quando houver conflito com outro mod.

## Remova dados sensíveis

Antes do upload, procure por:

- token MineSkin;
- IP público ou privado que não deseja divulgar;
- senhas e credenciais de painel;
- caminhos com nome de usuário local;
- nomes, UUIDs ou mensagens privadas de jogadores.

Use o formulário [Relatar um bug](https://github.com/SousaLJ/minecraft-server-boost/issues/new?template=bug_report_pt.yml).
Vulnerabilidades devem seguir a [política de segurança](https://github.com/SousaLJ/minecraft-server-boost/security/policy).
