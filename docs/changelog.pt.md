# Changelog

## 1.0.0-beta.1

- Forge e NeoForge 1.21.1 / Java 21;
- kits comuns e Choice Kits;
- GUI vanilla server-only para Choice Kits e `/kit info`;
- permissões built-in e FTB Ranks;
- segurança do `/setskin`: node próprio, HTTPS, cooldown e concorrência limitada;
- token MineSkin fora da configuração sincronizada;
- mensagens server-side e quatro idiomas;
- primeiro login, retorno, saída e anúncios periódicos;
- `SEQUENTIAL`, `RANDOM` e `SHUFFLE`;
- `/msb announce`;
- remoção do módulo Fabric placeholder;
- build limpo automatizado em CI.
