# Available permission nodes

| Node | Action | Fallback |
| --- | --- | --- |
| `minecraftserverboostmod.command.kits` | `/kits` | OP 2 |
| `minecraftserverboostmod.command.kit.create` | Create kits | OP 2 |
| `minecraftserverboostmod.command.kit.edit` | Edit kits and choices | OP 2 |
| `minecraftserverboostmod.command.kit.delete` | Delete kits | OP 2 |
| `minecraftserverboostmod.command.kit.give` | Administrative delivery | OP 2 |
| `minecraftserverboostmod.command.kit.reset` | Reset progress | OP 2 |
| `minecraftserverboostmod.command.kit.reload` | Reload kits | OP 2 |
| `minecraftserverboostmod.command.kit.info` | Inspect kit | OP 2 |
| `minecraftserverboostmod.command.kit.claim` | Parent claim node | Service |
| `minecraftserverboostmod.command.kit.claim.<id>` | Kit-specific claim | Service |
| `minecraftserverboostmod.command.setskin` | Change skin | OP 2 |
| `minecraftserverboostmod.command.announce` | Manage announcements | OP 2 |

`/msb permission` remains protected directly by operator level 4.
