# Reporting a bug

A useful report lets maintainers reproduce the problem without access to your
server.

Include:

- exact Minecraft Server Boost version;
- Minecraft, modloader, and Java versions;
- dedicated or integrated server;
- permission backend and FTB Ranks version, when applicable;
- minimal sequence of commands or actions;
- expected and actual results;
- complete, sanitized `latest.log` and crash report;
- an isolation test when another mod may be involved.

## Remove sensitive data

Before uploading, search for:

- MineSkin token;
- public or private IP addresses you do not want to disclose;
- panel passwords and credentials;
- paths containing your local username;
- player names, UUIDs, or private messages.

Use the [English bug report form](https://github.com/SousaLJ/minecraft-server-boost/issues/new?template=bug_report_en.yml).
Vulnerabilities must follow the [security policy](https://github.com/SousaLJ/minecraft-server-boost/security/policy).
