# Minecraft 1.20.1

## Forge line

- Java 17;
- complete kit management;
- built-in permissions and external integration;
- skins through MineSkin;
- internal translations for `pt_br`, `en_us`, `fr_fr`, and `es_es`.

NeoForge is outside this release line. Its specialization exists only on the
Minecraft 1.21.1 line and remains under validation until the build is
confirmed.

## Fabric

Fabric 1.20.1 remains a future improvement. The shared kit logic is already
separated so lifecycle, paths, and permissions can receive loader-specific
adapters, but a Forge JAR must never be published or labeled as Fabric.
