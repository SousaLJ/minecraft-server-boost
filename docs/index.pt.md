# Minecraft Server Boost

O **Minecraft Server Boost** fornece ferramentas administrativas server-side para servidores Minecraft.

## 1.0.0-beta.1

| Recurso | Situação |
| --- | --- |
| Forge 1.21.1 / Java 21 | Beta atual |
| NeoForge 1.21.1 / Java 21 | Beta atual |
| Kits comuns | Disponível |
| Choice Kits | Disponível |
| GUI `/kit info` e seleção | Vanilla, server-only |
| Permissões built-in | Disponível |
| FTB Ranks | Integração opcional |
| Skins / MineSkin | Disponível |
| `/setskin` | Permissão, HTTPS, cooldown e limite de concorrência |
| Primeiro login / retorno / saída | Disponível |
| Anúncios periódicos | `SEQUENTIAL`, `RANDOM`, `SHUFFLE` |
| pt-BR, en-US, fr-FR, es-ES | Disponível |
