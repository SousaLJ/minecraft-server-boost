# Roadmap

The roadmap expresses intent, not guaranteed deadlines.

## Implemented lines

- [x] complete kit management;
- [x] simple public or restricted kit policy without internal groups;
- [x] versioned persistence and atomic writes;
- [x] built-in permissions;
- [x] built-in or external provider selection;
- [x] optional FTB Ranks integration;
- [x] MineSkin skins and cache;
- [x] four languages in the mod;
- [x] Forge 1.20.1 line;
- [x] Forge 1.21.1 migration with Java 21;
- [x] NeoForge 1.21.1 adapters in code;
- [x] public repository and bilingual documentation;
- [ ] add permission, cooldown, and rate limiting to `/setskin`;
- [ ] complete the NeoForge 1.21.1 build and dedicated validation;
- [ ] publish and broaden release validation.

## Next stage

- [ ] welcome messages;
- [ ] periodic and random announcements;
- [ ] message reload and test commands;
- [ ] diagnostics and metrics without personal data.

## Platform expansion

- [ ] Fabric 1.20.1 adapter;
- [x] Minecraft 1.21.1 line on Forge;
- [x] NeoForge 1.21.1 specialization in code;
- [ ] mark NeoForge 1.21.1 supported after testing;
- [ ] evaluate Fabric 1.21.1;
- [ ] documented data migration between release lines.
